# Переклад квестів сегментами (`tools/locales/segs.py`)

Підхід, перевірений на MAZE 2026-10-02 (Claude, вручну): 919 ключів = ~290 унікальних рядків; ціна — ~11% 5-годинного
ліміту за 766 ключів (партії 20 ключів «по-старому» ≈4% разом із розвідкою).

## Суть
- Агент не читає квест ключ за ключем. Скрипт ріже ru-тексти на рядки, формули `{…}` замінює на `{F}`,
  рядки без кирилиці (ASCII-схеми) пропускає, дублікати зливає → **список унікальних сегментів за частотою**.
- Агент перекладає партію сегментів (JSON `{ru-сегмент: uk}`), скрипт підставляє переклади у всі ключі, де відомі
  всі сегменти, повертає формули по порядку і пише через `quests.py put` (перевірка тегів там же).
- Словник квесту зберігається в `locales/quests/segs/<КВЕСТ>.json` — однаковий переклад повторів, легко рецензувати.
- Службові рядки (`Сообщение достижения критического значения параметром N`, `Параметр номер N: <>`, шкала
  `==$==<br>События:`) підставляються автоматично.

## Коли вигідно
`python3 tools/locales/segs.py stats` — частка унікального тексту. MAZE 0.31, DISK 0.39, ELUS 0.47, GAIDNET 0.52,
CITADELS/ROBOTS 0.58; **медіана 0.86** (PIZZA, STQ_BARON*, STQ_ATAMAN* ≈1.0). Сегментний режим — для квестів ≲0.7;
решта — звичайний `quests.py todo` (але `{F}` замість формул економить і там).

## Ризики (пильнувати при перекладі)
- Короткі сегменти без контексту («Далее», «- Он вышел!», варіанти відповідей): рід, відмінок, ти/ви. `todo` дає
  перший ключ сегмента — за потреби подивитися ключ у `ru/`/`en/`.
- Один переклад на всі входження: якщо в різних місцях треба по-різному — перекласти ці ключі звичайним `put`.
- Вірші й багаторядкові абзаци ріжуться по рядках — перекладати партією разом, зберігаючи кількість рядків.

## Робочий цикл
    python3 tools/locales/segs.py todo КВЕСТ 60 > /tmp/x.json   # сегменти + перший ключ
    # перекласти в /tmp/b1.json: {"ru-сегмент": "uk", ...} — ключі дослівно з todo, {F}/<теги> як є
    python3 tools/locales/segs.py add КВЕСТ /tmp/b1.json        # словник + put повних ключів
    python3 tools/locales/quests.py check КВЕСТ
